# Manual File Generator (Node.js)

Reads the Operations Excel template and generates fixed-width test files for:
- Pledge Invocation (910)
- BO-to-BO (904)
- IDT (925; NSDL to CDSL)

## Requirements
- Node.js 18 or newer
- Completed Excel workbook (`.xlsx`)

## Setup
1. Extract this folder.
2. Open a terminal in the folder.
3. Run `npm install`.

## Generate files
Save the completed Operations workbook in this folder, then run:

```bash
node generate.js --input "NSDL_Operations_Trade_Input_Template(1).xlsx" --outdir output
```

Only sheets with trade inputs are generated. Each generated file includes:
- Opening and closing `{}` markers
- Fixed-width header, detail and trailer records
- Spaces/zeroes per the supplied technical specifications
- Automatic checks for record lengths, markers, batch consistency and single-detail count

Output filenames include the transaction type and batch number to avoid collisions if different transaction types use the same batch number, e.g. `idt-0000002.txt`. The upload copy should be renamed to exactly `<Batch Number>.txt` if the upload portal requires it.

## Built-in self-test
```bash
node generate.js --self-test
```

This creates sample records in memory and checks expected line lengths:
- Pledge: 2, 50, 300, 150, 2
- BO-to-BO: 2, 50, 600, 150, 2
- IDT: 2, 50, 600, 150, 2

## Excel input conventions
The workbook is read as a key/value sheet: field name in column A, value in column D. Field labels should not be renamed.
- `Quantity`: enter e.g. `1000` or `1000.123`. It is encoded to 15 digits with 3 implied decimal places.
- `File creation Date & time`: use `YYYYMMDDHHMM`, e.g. `202610221130`. If omitted, current local date/time is generated.
- IDs should be stored as text to preserve leading zeroes.
- Each populated trade column generates one detail record. The header detail count is calculated automatically, and line numbers are assigned sequentially. Batch Number, DP ID/Client ID, and File creation Date & time must be the same across all trade columns in a sheet because they belong to one output batch.
- Batch number and source DP ID/client ID are read from the workbook. Pledgee DP ID and Pledgee Client ID are static values: `IN987654` and `88888888`.
- Static values are generated by the program: record types, transaction types, flags, reason code `01`, payment mode `03`, stamp duty indicator `1`, without-consideration flag `N`, filler fields and trailer defaults.

## Important
This is a test-file generator, not a certification tool. Passing local checks does not guarantee upload acceptance. Review the applicable specifications and test responses before any production use.
